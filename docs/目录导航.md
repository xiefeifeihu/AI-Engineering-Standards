## 命名约定

1. 规范编号（如 `STD-035`）、Schema 文件名、CLI 参数、Python 模块路径和机器枚举保持原样。
2. 面向人的标题统一使用“中文名称（English Name）”。
3. 本次不批量重命名目录或文件；路径迁移会破坏 Markdown 链接、脚本导入、Git 子模块路径和消费工程引用，必须单独评估并提供兼容迁移。
4. 阅读规范正文时，优先从 [文档总索引](./DOCUMENT-INDEX.md) 进入；了解工具接入时，阅读 [消费端接入与工具使用协议](./Standards消费端接入与工具使用协议.md)。
